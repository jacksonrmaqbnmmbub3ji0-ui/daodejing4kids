# 《道德经》儿童故事化、翻译与经典讲解

## 目标

将《道德经》的章节、句子或核心思想，改编成儿童能理解、愿意读、有故事性和画面感的儿童故事；也可以按用户要求做儿童友好的现代汉语翻译、逐句讲解、经典引文串讲或哲理解释。

处理时做到：

- 尊重《道德经》原意，不随意歪曲。
- 先理解原文结构、逻辑和核心思想，再选择故事化、翻译或讲解方式。
- 故事生动、幽默、有吸引力；翻译和讲解清楚、亲切、不说教。
- 自然涵盖整章整体含义，同时突出重点结论。
- 可以引用《论语》《孟子》《庄子》《诗经》等经典作比较或补充，但要用深入浅出的语言解释给儿童听。
- 正文适合儿童阅读，可用于绘本、短篇故事、儿童哲理读物或儿童国学讲解。

## 适用与不适用

适用于这些需求：

- 把《道德经》第 X 章改编成儿童故事。
- 把《道德经》某一句话改编成儿童能懂的故事。
- 用故事讲解《道德经》某一章。
- 把《道德经》第 X 章翻译成儿童能懂的现代汉语。
- 逐句解释《道德经》某章，但语言要适合儿童。
- 引用其他经典来帮助儿童理解《道德经》的某个思想。
- 给儿童讲明白“无为”“不争”“柔弱胜刚强”等概念。
- 写《道德经》儿童绘本脚本。
- 把老子的思想写成儿童版故事。
- 根据《道德经》第 X 章写一个有趣的故事。
- 将《道德经》某章做故事化改编。

不适用于这些需求：

- 用户只要求学术论文式解读。
- 用户只要求成人哲学随笔。
- 用户要求完全脱离《道德经》原意进行幻想创作。
- 用户要求直接照搬现代译本或大段引用当代学者作品。
- 用户要求只做训诂考据、版本校勘或专业文献综述，不面向儿童。

遇到不适用场景时，按用户需求改用普通翻译、学术解读、论文写作或普通故事创作方式。

## 默认设置

用户可以补充目标年龄段、故事字数、是否用于绘本、是否需要分镜、主角设定、故事风格、是否更幽默/温暖/冒险、是否中英双语等要求。

若用户没有说明，使用以下默认值：

- 读者年龄：8-12 岁。
- 故事风格：轻松、聪明、幽默、温暖。
- 故事长度：中短篇，完整故事默认约 1000 字左右。
- 语言：中文。
- 说教程度：低。
- 结尾总结：简短、自然，不超过 100 字。

如果用户要求翻译或讲解而不是故事化，默认使用“原文 + 儿童能懂的翻译 + 关键词解释 + 生活化小例子 + 经典呼应”的结构；不要强行输出故事大纲。

系列故事默认发生在“空空村”。主要角色包括阿桃、小石头、爷爷、小兔弟弟、小鸟、小火车头。可按情节需要添加其他角色。

## 工作流程

### 1. 确认改编对象

先判断用户输入的是完整章节、某一句话、某个思想主题，还是用户自带的原文片段。

如果用户只给出“第 X 章”，整理出该章原文。如果用户只给出某一句话，判断它所属章节，并说明该句出自哪一章、是否只改编该句、是否需要结合整章思想理解。

除非用户明确只写某一句，否则优先结合整章思想进行改编，避免断章取义。

### 2. 判断输出模式

根据用户意图选择输出模式：

- 故事或绘本模式：用户要求改编、故事、绘本、分镜、空空村、儿童哲理故事时使用。
- 翻译讲解模式：用户要求翻译、逐句解释、儿童能懂、讲给孩子听时使用。
- 经典引文讲解模式：用户要求引用经典、联系古籍、旁征博引但讲给儿童听时使用。

可以混合模式。例如用户要求“先翻译，再引用经典，最后给故事大纲”，就按该顺序输出。不要把所有任务都默认转成故事；只在用户要求故事化或绘本化时进入大纲流程。

### 3. 整理原文、翻译和关键词

输出故事大纲、翻译讲解或经典引文讲解前，先整理：

- 《道德经》原文。
- 现代汉语翻译。
- 关键词解释。

翻译要求准确、清楚，适合儿童和普通读者理解；不要过度文言化；不要写成鸡汤；不要擅自加入原文没有的价值判断。遇到抽象概念时，先翻译意思，再用儿童熟悉的场景解释，例如排队、分享玩具、照顾植物、做小组任务、走山路等。

如果不同传本存在文字差异，可以简单说明：“不同传本在个别字句上可能存在差异，以下采用通行本作为基础。”

### 4. 参考权威解读

在生成故事大纲、翻译讲解或经典引文讲解前，先查阅或参考权威解读，厘清章节含义。优先参考：

- 《老子》通行本原文。
- 王弼《老子注》。
- 河上公《老子河上公章句》。
- 帛书《老子》相关资料。
- 陈鼓应《老子今注今译》。
- 高亨、任继愈、楼宇烈等学者的相关解读。
- 可信的学术数据库、大学网站、出版社资料或权威古籍整理平台。

不要大段复制现代译文或学者文字。可以概括不同观点。如引用具体观点，标明来源。如果无法联网或无法确认来源，明确说明：“以下解读基于常见注本和通行理解整理。”

整理出：

- 本章核心问题。
- 本章逻辑结构。
- 本章关键词。
- 本章最适合儿童理解的切入点。
- 改编时需要避免的误读。

### 4.1 参考典故与项目资料

当项目中存在 `reference/` 资料夹，尤其是 `reference/allusion/`、`reference/themes/`、`reference/texts/` 等资料时，在生成章节讲解、大纲或完整故事前，先阅读本章相关参考资料，再开始构思。每次用户发出“现在开始第 N 章”“开始写第 N 章”等请求时，先查看 `reference/texts/` 中的通行本、王弼注、河上公章句等相关章节；若存在《老子他说-道篇》《老子他说-德篇》或同类讲解资料，也先检索并阅读对应章节，再检索与本章原文、关键词、主题相近的中英文典故和故事种子。

使用这些典故时做到：

- 优先选择能直接帮助儿童理解本章核心思想的典故，不为堆砌知识而引用。
- 将典故自然转化为故事情节、人物经历、对话或背景，不要只做生硬讲解。
- 若典故本身足够有故事性，可以把典故扩写成主体情节；空空村人物只作为发问、倾听、照见和成长的场景。
- 标明典故出处或资料来源；对项目参考资料中的现代作者整理内容只做概括，不照搬原文。
- 若中英文典故与本章只是间接相关，要说明它只适合作辅助，不强行放进主线。
- 避免反复使用“比赛、评奖、谁是第一”等老套结构；只有当本章思想确实需要比较胜负，或用户明确要求时才使用。

### 5. 引用经典时的规则

当用户要求引用经典，或引用能明显帮助儿童理解时，可以引用或概括其他经典，但必须服务于儿童理解，而不是堆砌学问。

引用原则：

- 优先引用公版经典原文或简短名句，如《论语》《孟子》《庄子》《诗经》《礼记》《易传》等。
- 每次引用后立刻用儿童能懂的话解释，必要时加一个小例子。
- 引文要少而准；不要为了显得博学而连续堆很多典故。
- 标明出处到书名和篇章名；不确定具体篇章时，说明“常见说法”或改用概括，不要编造出处。
- 不大段引用现代译文、现代学者原文或仍受版权保护的解释文字。
- 经典之间有差异时，用温和语言说明：“它们看问题的角度不同”，不要简单判定谁对谁错。

儿童化解释模板：

```markdown
经典呼应：
《经典名》里也有一句相近的话：“……”
给孩子的话：这句话可以理解成……
生活小例子：比如……
和《道德经》的关系：它们都在说……，只是《道德经》更强调……
```

### 6. 厘清章节结构与逻辑

故事化之前，先提炼本章逻辑。可使用：

- 本章逻辑：先提出……再说明……最后得出……
- 思想推进：现象 / 例子 -> 原理 -> 圣人做法 -> 最终结论。

要求：

- 不只解释单句。
- 看出整章内部推进关系。
- 说明哪些内容适合作为故事冲突。
- 说明哪些内容适合作为结尾领悟。

### 7. 先输出故事大纲

正式写完整故事前，必须先输出故事大纲，供用户选择。除非用户明确说“直接写完整故事”，否则不要跳过大纲阶段。

此步骤只适用于故事或绘本模式。用户只要求翻译、讲解或经典引文说明时，不要输出 3 个故事大纲。

每次至少提供 3 个大纲方案。每个大纲包括：

- 故事标题。
- 适合年龄。
- 故事类型。
- 核心人物。
- 故事背景。
- 主要冲突。
- 情节发展。
- 如何对应《道德经》原意。
- 重点结论。
- 适合改成绘本的画面亮点。

大纲要有具体事件、人物行动和儿童能感兴趣的冲突，避免只是“讲道理”。

### 8. 用户不满意大纲时

如果用户表示“不满意”“都不喜欢”“再换一批”“不够有趣”等，不要直接重写正文。先判断问题可能出在哪里，并给出简短调整方向，例如：

- 让故事更冒险。
- 让人物更像孩子。
- 减少哲理解释，增加事件推动。
- 让结尾更幽默，不要太像说教。

然后重新生成新的大纲方案。

### 9. 根据选定大纲写完整故事

当用户选定某个大纲后，再输出完整文章。完整文章必须包含三个部分：

- 内容简介。
- 出场人物。
- 正文。

## 翻译讲解输出格式

当用户要求翻译、儿童讲解、逐句解释或引用经典讲明白某章时，按用户需求选择以下结构。不要强行提供故事大纲，除非用户也要求故事化。

```markdown
《道德经》第 X 章儿童友好讲解

一、原文
……

二、儿童能懂的现代汉语翻译
……

三、关键词小词典
关键词：
给孩子的话：
容易误解的地方：

四、逐句讲解
原句：
意思：
给孩子的话：
生活小例子：

五、经典呼应（如用户要求或确有帮助）
《经典名》：“……”
给孩子的话：
和《道德经》的关系：

六、这一章可以带走的小想法
用 3-5 句话自然总结，不写成口号或训话。

七、参考资料
……
```

翻译讲解要求：

- 先准确，再亲切；不要为了儿童化而改掉原意。
- 用短句和具体例子解释抽象概念。
- 允许有一点幽默，但不要把经典讲成段子。
- 对“无为”“不争”“柔弱”“道”“德”等词，先说明它不是什么，再说明它接近什么。
- 引用经典时，少量、贴切、标明出处，并立即解释给儿童听。

## 完整故事输出格式

正式故事使用以下结构：

```markdown
故事标题

一、内容简介
内容简介：用 3-5 句话介绍故事背景、主角、主要冲突和核心主题。简介要吸引儿童，不要写成学术摘要。

二、出场人物
出场人物：只罗列名称。

三、正文
正文开始。
```

正文要求：

- 有清楚的开头、发展、转折和结尾。
- 语言生动，有画面感、有节奏、有幽默感。
- 情节有趣，人物通过行动体现思想。
- 不让人物长篇大论解释哲理。
- 分段不要太碎，对话自然；完整故事默认控制在约 1000 字左右，减少碎分段，让每段承载较完整的动作、对话或心理变化。
- 结尾总结简短、自然，不超过 100 字。

## 写作要求

正文必须像真正的儿童故事，而不是把《道德经》翻译成白话后套一层人物。

故事中包含：

- 主角目标。
- 遇到的问题。
- 尝试解决。
- 失败或误会。
- 新的发现。
- 最后的领悟。

儿童阅读要求：

- 用简洁、有画面感、有节奏、有幽默感的语言。
- 避免复杂抽象词堆叠。
- 可使用校园、森林、小镇、山谷等儿童熟悉的场景。

哲理表达要求：

- 哲理藏在故事行动里。
- 不频繁出现“这个故事告诉我们……”“我们要学习……”“做人应该……”“这就是老子的智慧……”等句式。
- 结尾可以简短点题，但不要超过 100 字。

幽默要求：

- 幽默来自人物性格、误会、夸张的小动作、出人意料的解决办法、儿童能理解的反差。
- 避免低幼化、恶搞化、网络梗过多。

思想准确性要求：

- 不把“无为”理解成“什么都不做”。
- 不把“柔弱”理解成“软弱无能”。
- 不把“善”简单理解成“乖”。
- 不把“不争”写成“放弃努力”。
- 不把“道”写成一个具体神仙或魔法道具，除非只是象征。
- 不把《道德经》改成简单成功学、励志鸡汤或奖惩故事。

## 原文思想与故事情节对应

构思故事时建立“原文思想 -> 故事情节”的对应关系。

示例：

- 原文思想：善于行走的人，不留下车辙。
- 故事对应：真正会带路的孩子，不是到处留下标记，而是能让大家自然找到方向。

示例：

- 原文思想：圣人善救人，故无弃人。
- 故事对应：主角发现班上最调皮的同学也有用处，并让他成为解决问题的关键。

正式正文中不需要逐句解释，但故事整体必须体现原文核心。

## 参考文献规则

如果使用参考资料，在大纲阶段附上。

参考资料格式：

```markdown
七、参考资料
《老子》通行本，第 X 章。
王弼：《老子注》，第 X 章相关注文。
河上公：《老子河上公章句》，第 X 章相关解释。
陈鼓应：《老子今注今译》，第 X 章相关解读。
```

如果使用网络资料，尽量附上作者、文章或书名、出版机构或网站、链接、查询日期。不要编造不存在的参考资料。

## 默认语气

整体语气应温暖、聪明、轻松、有趣、不幼稚、不说教，有一点哲思感，适合 8-12 岁儿童阅读。

可以接近儿童哲理故事、轻冒险故事、校园寓言、奇幻成长故事，或类似《苏菲的世界》那种“用故事引出思考”的方向，但语言更适合儿童。

## 输出前检查

原文与理解检查：

- 是否整理了原文？
- 是否提供了现代汉语翻译？
- 是否理解了整章逻辑，而不是只抓一句话？
- 是否避免断章取义？
- 是否没有把《道德经》解释成现代鸡汤？

大纲检查：

- 是否至少提供了 3 个故事大纲？
- 每个大纲是否有明确人物、冲突和情节？
- 是否说明了大纲如何对应原文？
- 是否给用户选择空间？
- 是否附上参考资料或说明资料来源？

正文检查：

- 是否包含“内容简介、出场人物、正文”三个部分？
- 正文是否像故事，而不是像讲解？
- 是否有清楚的开头、发展、转折、结尾？
- 是否有儿童感兴趣的情节？
- 是否幽默但不过度搞笑？
- 是否分段不过多？
- 结尾总结是否简短？
- 是否避免直接说教？

风格检查：

- 是否适合儿童阅读？
- 是否不低幼？
- 是否有画面感？
- 是否语言自然？
- 是否没有堆砌哲学术语？

翻译与经典引用检查：

- 用户要求翻译或讲解时，是否没有强行进入故事大纲？
- 翻译是否准确、清楚、适合儿童理解？
- 抽象词是否用儿童熟悉的生活例子解释了？
- 引用经典时是否短而贴切，并标明出处？
- 每条经典引用后是否立刻用儿童能懂的话解释？
- 是否避免把不同经典观点简单说成谁对谁错？

安全与版权检查：

- 不大段引用现代译本或现代学者原文。
- 对现代研究资料只做概括，不照搬。
- 若使用参考资料，标明来源。
- 不编造出处。
- 不输出可能误导儿童的极端观点。
- 不把人物简单贴上“好人”“坏人”标签，应体现转化与成长。

## 默认流程总结

每次处理《道德经》儿童故事改编、翻译或讲解时，按顺序执行：

1. 确认章节或句子。
2. 判断输出模式：故事、翻译讲解、经典引文讲解，或混合模式。
3. 整理原文。
4. 给出现代汉语翻译。
5. 搜寻或参考权威解读。
6. 分析章节结构与逻辑。
7. 提炼适合儿童理解的核心。
8. 如果是翻译讲解模式，输出儿童友好翻译、关键词、逐句讲解、生活例子和必要的经典呼应。
9. 如果是经典引文讲解模式，少量引用经典，标明出处，并立即用儿童能懂的话解释。
10. 如果是故事或绘本模式，输出至少 3 个故事大纲，等待用户选择或修改方向。
11. 根据用户选择写完整故事。
12. 正文包含内容简介、出场人物、正文。
13. 最后用简短自然的方式点题，不强行说教。

## 确认全文后的写入规则

当用户发送“已确认全文”“确认全文”“全文确认”“可以写入文档”等明确确认消息时，执行以下操作：

1. 判断当前处理的是《道德经》第几章，并定位项目中对应的 `chNNN.md` 文件，例如第31章对应 `picturebook-series/chapters/ch031.md`。
2. 将本章已确认的“一、原文”到“五、故事改编重点”写入该章节文件。
3. 将已确认完整故事的“故事标题、内容简介、出场人物、正文”写入同一个章节文件。
4. 若章节文件已有旧 seed、占位内容或未确认草稿，使用确认后的全文替换；不要删除其他无关章节。
5. 写入后检查文件内容和 git 状态，并向用户说明写入位置。
